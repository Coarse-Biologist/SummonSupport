
# Project Instructions

## Project
- Unity 6, URP.
- Craft minions
- Fight with friends against mob storms
- Support allies and summons
- Loot and craft stronger minions and abilities
- Mod and upgrade minions and abilities and player stats
- C#.

## Coding Rules
- Do not code ugly temporary band-aid fixes.
- Solve root causes, not symptoms
- Follow existing project architecture and naming conventions.
- Prefer modifying existing scripts over creating duplicate systems.
- Avoid unnecessary abstractions and dependencies.
- Don't modify unrelated files.
- Inspect relevant scripts before implementing changes.
- Explain significant architectural changes before making them.

## Version Control
- Treat the branch you start in as "Main", create branches from that and pull and commit to it.

## Unity
- Use Unity 6-compatible APIs.
- Preserve serialization compatibility.
- Avoid deprecated Unity APIs.
- Consider performance and garbage allocation.
